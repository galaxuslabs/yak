# next-yak 10

next-yak is now [@yak/react](https://www.npmjs.com/package/@yak/react). This branch releases next-yak 10, which only contains a codemod that moves a project from next-yak to @yak/react:

```bash
npx next-yak migrate
```

The [migration guide](https://yak.style/docs/migration-from-next-yak) explains each step. The source of @yak/react is on the [main branch](https://github.com/galaxuslabs/yak), and next-yak 9 gets fixes on the [v9 branch](https://github.com/galaxuslabs/yak/tree/v9).
